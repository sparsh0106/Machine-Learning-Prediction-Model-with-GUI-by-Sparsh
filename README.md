# 📈 Machine Learning Prediction Model with Tkinter GUI

An interactive desktop GUI application built with **Python**, **Tkinter**, and **scikit-learn** that trains a **Linear Regression** model on user-supplied sequential data points in real time, predicts the next value in the series, and reports the model's $R^2$ accuracy score.

---

## 📂 Repository Structure

- `main.py`: Complete Tkinter GUI application and `scikit-learn` Linear Regression pipeline.
- `README.md`: Project documentation and download links.

---

## ✨ Features

- **Interactive 10-Point Data Input**: Enter 10 sequential numerical observations directly into the Tkinter interface.
- **Automated Train/Test Split & Fitting**: Splits the input series (`train_test_split`), fits a `LinearRegression` model, and forecasts the $11^{	ext{th}}$ data point.
- **Real-Time Model Evaluation**: Computes and displays the model's $R^2$ accuracy percentage directly in the GUI window.

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sparsh0106/Machine-Learning-Prediction-Model-with-GUI-by-Sparsh.git
   cd Machine-Learning-Prediction-Model-with-GUI-by-Sparsh
   ```

2. **Install dependencies**:
   ```bash
   pip install pandas numpy scikit-learn scipy seaborn matplotlib
   ```

3. **Run the application**:
   ```bash
   python main.py
   ```
